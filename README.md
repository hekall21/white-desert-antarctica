## 🧭 Key Experiences & Sections

1. **Hero Experience:** Full-bleed polar landscape with subtle Ken Burns cinematic motion, active GPS coordinates (`71°32'47" S, 8°50'11" E`), weather telemetry (`-18°C`), and film reel player.
2. **Signature Polar Voyages:** 4 curated expeditions:
   - *Emperor Penguins Colony* (Atka Bay Imperial Sanctuary)
   - *The South Pole & Emperors* (Geographic 90° South Summit)
   - *Glacier Ice Tunnels & Blue River* (Hidden Sub-Glacial Labyrinths)
   - *Greatest Day: 24h Antarctica* (Fastest Polar Crossing on Earth)
3. **Astronaut-Inspired Heated Pods:** Bento-grid showcase of *Echo Camp* (Futuristic Sky-Pods) and *Whichaway Camp* (Freshwater Oasis Domes).
4. **Private Aviation Logistics:** Interactive flight trajectory visualizer from Cape Town FBO lounge, Gulfstream G550 flight across the Southern Ocean, touchdown on Wolf's Fang 3,000m Blue Ice Runway, and Basler BT-67 turbo ski-plane transfers.
5. **Pioneering Conservation & IAATO:** The story of founders Patrick & Robyn Woodhead (Guinness World Record explorers) and White Desert's 100% Carbon Neutral commitment since 2007.
6. **Bespoke Concierge Modal:** Encrypted reservation system for private jet charters and luxury pod buyouts.

## 🛠️ Tech Stack & Architecture

- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS v4 (`@theme` variables, zero config)
- **Icons:** Lucide React
- **Animations:** Framer Motion 13

```bash
# Clone & install dependencies
git clone https://github.com/hekall21/white-desert-antarctica.git
cd white-desert-antarctica
npm install

# Run local development server
npm run dev

# Build production bundle
npm run build
```
